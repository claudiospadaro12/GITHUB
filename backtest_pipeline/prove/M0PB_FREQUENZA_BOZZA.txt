# =====================================================================
#  IPOTESI
# ---------------------------------------------------------------------
#  Un RSI(6) che tocca 90 (o 10) segnala uno squilibrio di flusso VERO
#  in una direzione. Chi insegue l'impulso paga il prezzo peggiore; chi
#  aspetta il RIENTRO sulla EMA(5) dei minimi (o dei massimi) compra lo
#  stesso squilibrio al prezzo migliore, e ha davanti lo spazio fino al
#  massimo mobile delle ultime 12 barre.
#
#  MA IL PUNTO DI QUESTO PASSO 0 NON E' L'EDGE. E' PRIMA:
#  il meccanismo produce ABBASTANZA OCCASIONI (>= 1 al giorno) e con
#  ABBASTANZA SPAZIO (>= 3x lo spread) da meritare che gli si scriva un
#  EA? Se anche una sola delle due risposte e' no, il candidato muore
#  qui e NON si spende una macchina.
#
# =====================================================================
#  CRITERI DI ACCETTAZIONE (CONGELATI PRIMA DI VEDERE QUALUNQUE NUMERO)
# ---------------------------------------------------------------------
#  F1 - PAVIMENTO DI FREQUENZA (pavimento duro, di Claudio 31/08):
#       segnali per LATO >= 1 al giorno di calendario di borsa.
#       < 1/giorno  -> SCARTO IMMEDIATO. Niente EA, niente griglia.
#       1-2/giorno  -> PASSA, ma al minimo.
#       > 2/giorno  -> PASSA nella fascia preferita da Claudio.
#
#  F2 - TAGLIA DEL TAKE (metro di casa C2):
#       mediana della distanza ingresso -> highest(12)/lowest(12),
#       misurata AL MOMENTO DEL SEGNALE, in punti indice.
#       >= 6,0 punti  -> PASSA   (3 x 2,0 punti di spread di riferimento)
#       <  5,0 punti  -> SCARTO
#       fra 5,0 e 7,0 -> VERDETTO SOSPESO: si misura finalmente lo
#                        spread vero col Code Base 74148 (RealCost
#                        Spread P95 Logger, promosso il 23/08 e MAI
#                        ancora usato) e si rilegge.
#       ATTENZIONE: 2,0 punti indice e' una STIMA dichiarata di
#       METRO_PROP D4, NON una misura. E' marcata [SPREAD NON MISURATO]
#       in ogni referto finche' 74148 non gira.
#
#  F3 - RR VERO, da leggere prima di qualunque numero di merito:
#       mediana della distanza ingresso -> stop (2,75 x ATR(10)).
#       Nessun cancello: e' un numero DA CONOSCERE. Se il take mediano
#       e' molto piu' piccolo dello stop mediano, il motore e' ad alto
#       win rate e RR basso, cioe' la forma che il DD TRAILING delle
#       prop punisce (METRO_PROP, Upcomers). Va scritto nel referto,
#       non scoperto dopo.
#
#  F4 - MURO GIORNALIERO PROP:
#       massimo numero di segnali in UNA SOLA giornata, e giornata in
#       cui e' successo. E' il numero che taglia InpMaxTradesPerDay sui
#       dati invece che a occhio. Riferimento: la peggior giornata mai
#       misurata in casa e' -2,06% (R51) con motori a ~1 trade/giorno;
#       il muro prop e' -5,00% in una sola giornata.
#
#  F4-bis - CANCELLO H8 (FIRMATO DA CLAUDIO IL 31/08 SERA,
#           report\FIRME_2026-08-31.md, FIRMA 2, testuale:
#           "Ogni motore ad alta frequenza entra in flotta SOLO con
#            E >= 0.075R misurata A TICK. Frequenza sotto questo
#            cancello = portata finta (DD e costi). Vale per tutti i
#            promossi della caccia-frequenza, da oggi.")
#
#       La sonda deve restituire il RR MEDIANO:
#            RR = (mediana take)  /  (mediana stop)
#                = (numero F2)    /  (numero F3)
#
#       Da E = p*RR - (1-p) si ricava il win rate NECESSARIO per
#       superare 0,075R. Tabella calcolata PRIMA di vedere i numeri:
#
#            RR = 0,36  ->  serve win rate 79,0%   IRREALISTICO
#            RR = 0,50  ->  serve win rate 71,7%   sopra il dichiarato
#            RR = 0,73  ->  serve win rate 62,2%   al limite
#            RR = 1,00  ->  serve win rate 53,8%   comodo
#
#       CANCELLO: RR mediano < 0,70  ->  SCARTO PER ARITMETICA, e NON
#       si spende una corsa a tick. Con lo stop da 2,75 ATR dell'autore
#       nessun win rate plausibile porterebbe E a 0,075R: sarebbe
#       PORTATA FINTA, la cosa esatta che la FIRMA 2 esiste per non
#       comprare.
#
#       CONSEGUENZA SUL PIANO, dichiarata adesso: il parametro che
#       decide NON e' l'RSI, e' InpAtrStopMult -- che guarda caso e'
#       l'UNICO input libero lasciato dall'autore, cioe' la manopola
#       che ha girato lui. Quando (e se) si arrivera' allo sweep,
#       si parte da li'.
#
#  F5 - DUE LATI, SEMPRE E SEPARATI (regola di Claudio del 25/08).
#       I quattro numeri sopra si producono per il LONG e per lo SHORT
#       distintamente. Mai un totale aggregato.
#
#  F6 - GRADIENTE DI TIMEFRAME, dichiarato prima:
#       la sonda gira su M5 E su M15. Ci si aspetta piu' segnali e take
#       piu' piccoli a M5. Il gradiente di casa (R108/R111) dice
#       H1 > M30 > M15 sull'EDGE: se qui la taglia crolla a M5, e' la
#       stessa curva vista dall'altro lato, e va detto.
#
