#
#   L'EA nasce per il Nikkei di **Darwinex** e converte JST -> ora server

#   d'inverno**, con la regola DST **americana**. Su BCM sarebbe SBAGLIATO
#   DI DUE ORE. Un EA di sessione con l'ora sbagliata misura un altro
#   mercato — e questa non e' una battuta: leggerebbe il "range di
#   apertura" alle 03:00 server, cioe' a meta' mattinata di Tokyo.

#   Percio' NON usiamo il modo automatico. Usiamo il modo MANUALE che

#   IL CALCOLO, per esteso, come pretende il dossier:
#     seduta cash di Tokyo (TSE)      09:00 -> 15:30  JST
#     JST = UTC+9, tutto l'anno (il Giappone NON fa l'ora legale)
#       09:00 JST - 9h = 00:00 UTC      15:30 JST - 9h = 06:30 UTC
#     ora italiana (agosto, CEST = UTC+2)
#       00:00 UTC + 2h = 02:00 IT       06:30 UTC + 2h = 08:30 IT
#     ora server BCM = ora italiana - 1  (regola fissa di progetto)
#       02:00 IT - 1h = **01:00 server** 08:30 IT - 1h = **07:30 server**
#
#     ✅ CONTROPROVA con la regola nota: il DAX apre 09:00 IT = 08:00
#        server, quindi d'estate il server BCM sta a **UTC+1**.

#   🔴 IL BUCO CHE DICHIARO ADESSO, NON DOPO — L'ORA LEGALE.
#      01:00/07:30 e' esatto quando il server BCM sta a UTC+1, cioe'
