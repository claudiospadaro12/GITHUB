# IPOTESI
#   Il range della sessione europea mattutina (09:35-12:05 CET = 08:35-11:05
#   SERVER BCM) definisce il valore del giorno. Nella fascia sottile
#   12:05-15:15 CET (= 11:05-14:15 SERVER) una rottura degli estremi che poi
#   RIENTRA (reclaim confermato a barra chiusa) e' una FALSA rottura: il
#   prezzo torna verso l'estremo opposto. Sweep+reclaim sul range MATTUTINO,
#   su INDICE M5 (non forex come R95, non alla campanella come R42). Il
#   reclaim CONFERMATO E' il motore -- e' la conferma che a R42 mancava.
#
# CRITERI DI ACCETTAZIONE  (congelati PRIMA dei numeri)
#   - PASSO 0 (cancello S0, PRIMA di ogni PF): costruire l'EA, contare le
#     operazioni (>=150 per il merito, altrimenti valvola R59: rischio si',
#     merito sospeso) e verificare che il LORDO medio/operazione sia >= 3x lo
#     SPREAD della fascia mezzogiorno (liquidita' sottile: il costo e' il
#     CRITERIO, non un contorno). Se il lordo non copre 3x lo spread -> STOP.
#   - Verdetto SOLO a tick reali (modello 4). OHLC 1-min = solo conteggio.
#   - Si giudica per REGIME dichiarato (21 mesi BCM = un solo regime toro:
#     rischio si', merito sospeso).
#   - Promozione cella: CENTRO dell'altopiano, MAI il picco.
#     >>> QUESTO LANCIO E' PASSO 0 + MISURA, NON IL VERDETTO: qui NESSUNA
#     cella viene promossa (la selezione centro-vs-picco e' del round di
#     griglia che verra' DOPO la misura, se il cancello S0 passa).
#   - DUE LATI misurati sempre (long E short), regola di casa 25/08.
#   - CAP GIORNALIERO OBBLIGATORIO (controtendenza in trend forte = serie
#     perdenti): default 2/gg, 1/lato.
#   - SL VERO al broker con PAVIMENTO (R109): InpMinStopPts, mai zero.
#   - FLAT a fine seduta (ora server), zero overnight.
#     >>> VINCOLO RISCRITTO 31/08 (PRIMA dei numeri, classe NyRetest): si
#     esige che nessuna posizione sopravviva al PRIMO TICK dopo il flat
#     (flat di RECUPERO nell'EA). Le chiusure a giorno successivo (giorni
#     SENZA tick fra flat e mezzanotte) si CONTANO nel wrapper: sopra il 5%
#     delle posizioni = file INVALIDO; sotto = RILIEVO col suo gap-risk.
#   - Deve battere i caduti: NON e' ORB (fade, non alla campanella), NON R42
#     (serve rottura-oltre + reclaim CONFERMATO), NON R95 (era forex M30-H4),
#     NON MaxMinNotte (box notturno vs mattutino). Se degenera -> scarto.
#   - SCORRELAZIONE (vincolo scritto PRIMA): i giorni-segnale NON devono
#     coincidere con MaxMinNotte_DAX_Short. Se scattano gli stessi giorni,
#     non aggiunge diversificazione -> penalita'.
#     >>> QUESTO LANCIO E' PASSO 0 + MISURA, NON IL VERDETTO: il banco non
#     produce l'incrocio coi giorni della sedia (serve il suo per-trade):
#     si misura DOPO, sui CSV, prima di qualunque promozione.
#
# DICHIARAZIONI DEL BANCO (PASSO 0 + MISURA, FrazioneIS 1.0)
#   - UNA TRANCHE: la gamba "IS" del generico e' la finestra intera, la
#     "OOS" e' DEGENERE (0 giorni) e si IGNORA. Il rosso del generico sul
#     CSV *_OOS e' ATTESO: NON rilanciare.
#     >>> QUESTO LANCIO E' PASSO 0 + MISURA, NON IL VERDETTO: il criterio
#     OOS non e' producibile qui (OOS inesistente per costruzione).
#   - ASSI VERI (sotto, flag Y): il per-trade CSV in griglia e'
#     INUTILIZZABILE come misura della griglia -- il nome porta il MAGIC
#     (fisso 769300) e ogni passata con uscite lo RISCRIVE: resta SOLO
#     l'ultima. La frequenza per cella si legge dalla colonna Trades della
