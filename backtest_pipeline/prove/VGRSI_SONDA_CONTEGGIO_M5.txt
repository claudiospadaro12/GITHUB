#  IPOTESI
# ---------------------------------------------------------------------
#  "Un RSI calcolato NON sulle differenze locali di prezzo, ma solo
#   sulle variazioni dei punti passati ancora VISIBILI dal punto
#   corrente (relazione di visibilita' all'indietro), misura la
#   struttura geometrica della traiettoria invece della sua sola
#   ampiezza -- e produce, su M5, abbastanza attraversamenti di soglia
#   da fare almeno 2 segnali al giorno PER LATO, con un'escursione
#   favorevole che vale almeno tre volte lo spread."
#
#  >>> QUELLO CHE L'IPOTESI *NON* DICE, e va detto:
#      non c'e' un meccanismo di MERCATO dietro (chi sta dall'altra
#      parte, perche' quel flusso esiste). E' una tesi GEOMETRICA, non
#      microstrutturale. Nel punteggio del dossier vale 1 punto su 2, ed
#      e' dichiarato li'.
#
# =====================================================================
#  LA FORMULA, VERBATIM DAL PAPER (sezione Methods, pagg. 3-5)
#  -- ricopiata qui perche' chi scrive l'indicatore non deve
#     ri-scaricare un PDF da 5,7 MB, e perche' una formula riassunta
#     e' una formula che diverge --
# ---------------------------------------------------------------------
#  DUE PARAMETRI STRUTTURALI:
#    WS = Window Size       (lunghezza su cui si aggrega)
#    WV = Window Visibility (raggio massimo della visibilita' indietro)
#
#  PASSO 1 -- VISIBILITA' ALL'INDIETRO.
#    Per ogni j nella finestra  j in {t-WS+1, ..., t}
#    si considerano solo gli indici passati
#           i in {j-1, j-2, ..., max(0, j-WV)}
#    Il punto (i, p_i) e' VISIBILE da (j, p_j) se, per OGNI k con
#    i < k < j:
#           p_k  <  p_j + (p_i - p_j)/(i - j) * (k - j)
#    cioe' se nessun punto intermedio sfora la retta che unisce
#    (i,p_i) a (j,p_j).
#    L'insieme dei visibili e' V_j; se ne usano al massimo WS
#    (sottoinsieme V_j^(WS), con |V_j^(WS)| <= WS).
#
#  PASSO 2 -- DALLA GEOMETRIA AI SEGNI.
#    Variazione locale:  dp_i = p_i - p_(i-1)
#    ATTENZIONE, dettaglio che si sbaglia facilmente e che il paper
#    dichiara esplicitamente: la visibilita' seleziona SOLO QUALI i
#    entrano nella somma; il dp_i si riferisce SEMPRE alla coppia
#    contigua (i-1, i), anche se i-1 NON e' visibile da j.
#
#    S+(t) = somma su j da t-WS+1 a t, somma su i in V_j^(WS), di (+dp_i) per dp_i>0
#    S-(t) = somma su j da t-WS+1 a t, somma su i in V_j^(WS), di (-dp_i) per dp_i<0
#    N+(t) = conteggio degli stessi contributi con dp_i > 0
#    N-(t) = conteggio degli stessi contributi con dp_i < 0
#
#  PASSO 3 -- DUE FORZE RELATIVE:
#    rS(t) = S+(t) / S-(t)          (ampiezza)
#    rN(t) = N+(t) / N-(t)          (frequenza)
#
#  PASSO 4 -- DUE VARIANTI DI AGGREGAZIONE:
#    A0 (media):   rA0(t) = 0.5 * ( rS(t) + rN(t) )
#    A1 (rapporto): rA1(t) = rS(t) / rN(t)
#
#  PASSO 5 -- NORMALIZZAZIONE 0..100:
#    VGRSI_rA(t) = 100 - 100/(1 + rA(t))
#
#  INTERPRETAZIONE DELL'AUTORE (utile per leggere i risultati):
#    A0 = filtro di TREND/persistenza (ampiezza E frequenza insieme).
#    A1 = misura di IMPULSO/rottura (pochi movimenti, grande ampiezza),
#         piu' sensibile ai falsi segnali.
#    A1 alto + A0 basso = impulso senza struttura (fakeout).
#    A1 alto + A0 in salita = impulso che diventa trend.
#
#  >>> 🔴 IL VINCOLO DI CALCOLO, MISURATO SULLA FORMULA E NON IPOTIZZATO
#      L'implementazione ingenua ricalcola tutti i V_j a ogni barra:
#      O(WS * WV^2) per barra. Con WS=WV=35 sono ~43.000 confronti per
#      barra: su 150.000 barre M5 sono ~6,4 miliardi di operazioni, e
#      NON GIRA nel tester.
#      LA FORMA DA SCRIVERE E' INCREMENTALE: a ogni barra nuova si
#      calcola UNA volta il set di visibilita' della barra nuova
#      (O(WV^2) = ~1.200 confronti) e si tiene una CODA delle ultime WS
#      barre, sommando il nuovo e togliendo il vecchio.
#      Costo risultante: ~1.200 operazioni/barra = ~1,8e8 su 150.000
#      barre. Gira.
#      >>> Il criterio V7 qui sotto MISURA questo, e se non regge il
#          candidato muore di costo. Si dichiara, non si nasconde.
