# ---------------------------------------------------------------------
#  MECCANICA DA IMPLEMENTARE (dal sorgente, righe 60-125)
# ---------------------------------------------------------------------
#  VOLATILITA' STORICA:
#     hv = stdev(log(close/close[1]), InpHvLen) * sqrt(252)   [annualiz.]
#     hvp = percentile di hv nelle ultime InpHvLookback barre
#  ATTIVAZIONE (l'ancora):
#     hvp > InpHvSoglia  E  hvp[1] <= InpHvSoglia    <- ATTRAVERSAMENTO,
#                                                       non "stare sopra"
#     Alla barra di attivazione si congelano:
#       ancHigh, ancLow, range = ancHigh - ancLow
#       liv100Up = ancHigh + range ;  liv100Dn = ancLow - range
#       liv50Up  = ancHigh + range/2 ; liv50Dn  = ancLow - range/2
#  RAMO CONTINUAZIONE:
#     chiusura > liv100Up -> LONG   |   chiusura < liv100Dn -> SHORT
#  RAMO ESAURIMENTO:
#     c'e' gia' stata l'estensione 100% da un lato, POI la chiusura e'
#     RIENTRATA dentro [ancLow, ancHigh], POI attraversa il 50% opposto
#       (estensione giu' fallita -> LONG ;  su fallita -> SHORT)
#  UNA sola operazione per attivazione.
#  Scadenza: l'ancora si spegne dopo InpAncoraBarre barre senza
#  ingresso (nel sorgente l'ancora vive finche' non arriva la
#  successiva -- va messo un tetto, altrimenti un'ancora vecchia di
#  tre settimane puo' ancora sparare).
#
#  >>> Tutto su BARRA CHIUSA.
#
