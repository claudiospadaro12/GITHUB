# ---------------------------------------------------------------------
#  IPOTESI
# ---------------------------------------------------------------------
#  Chi ha comprato la rottura dell'Initial Balance viene riportato sul
#  livello.  Li' si convince di essere in trappola.  Quando il livello
#  CEDE DI NUOVO, e' lui a doverlo vendere: il SECONDO passaggio ha
#  dietro liquidita' FORZATA, il primo no.
#
#  LA DOMANDA VERA, ed e' una sola:
#    la rottura di un livello di seduta in casa e' MORTA -- M1/ORB,
#    ~210 celle a tick, R45 0/48, R12 48/48 negative, capitolo M5
#    chiuso il 26/07.  Ma tutte quelle celle misuravano UN SOLO STATO:
#    "il prezzo esce dal box -> entro".
#    >>> Aspettare il RITORNO e operare solo il suo FALLIMENTO -- cioe'
#        SCARTARE per costruzione tutte le rotture che tengono al primo
#        colpo -- e' lo stesso motore o un altro?
#
#  PERCHE' LA DOMANDA HA SENSO:
#    Un ORB e questo motore, sulla stessa identica seduta, prendono
#    operazioni DIVERSE o nessuna.  Non c'e' una sola seduta in cui
#    facciano la stessa cosa: l'ORB entra al passo 1, questo al passo 3,
#    e se il passo 2 non arriva questo NON ENTRA AFFATTO.
#    >>> Non e' "un'altra griglia sull'ORB": e' una macchina a stati che
#        usa il livello dell'ORB come input e ne rifiuta il segnale.
#
# ---------------------------------------------------------------------
#  PERCHE' NON E' UN CADUTO  (lista completa nel dossier par. 4/P1)
# ---------------------------------------------------------------------
#    - NON e' M1/ORB (~210 celle, R45 0/48): l'ORB entra sulla rottura.
#      Qui la rottura NON e' un ingresso, e' il passo 1 di 3.
#    - NON e' M24 / CRT / Turtle Soup / BreakinBox (0/30 celle a tick):
#      quelli FADANO la rottura, entrano CONTRO.  Qui si entra NELLA
#      direzione della rottura.  SEGNO OPPOSTO.
#    - NON e' R42 (fade degli estremi del range d'apertura, 0/24 IS e
#      0/24 OOS): idem, quello e' contrarian sul livello.
#    - NON e' "NY First Candle Break and Retest" (biblioteca, 25/08):
#      li' il livello e' UNA candela di NY; qui e' un Initial Balance
#      da 60 minuti, e soprattutto li' non c'e' il TERZO stato (il
#      fallimento del ritorno).
#    - NON e' "InitialBalanceBO" (biblioteca, 28/08): quello e' un IB
#      breakout nudo.
#    - NON e' ABTG_DAX_Apertura_EU ne' ABTG_ORB_Ottimizzato (sedie
#      vive): quelle lavorano SULLA campanella; questo non puo'
#      nemmeno cominciare a guardare prima che l'IB sia CHIUSO.
#
# ---------------------------------------------------------------------
#  MECCANICA DA IMPLEMENTARE (dal sorgente, macchina a 3 stati)
# ---------------------------------------------------------------------
#  IB = massimo e minimo fra InpIbInizio e InpIbFine (ORA SERVER BCM!).
#
#  LATO SHORT (il long e' lo speculare esatto -- nel Pine e' scritto
#  due volte in modo simmetrico, righe 706-756 e 757-801):
#    S1  ROTTURA        minimo < IB_low                    (una volta)
#    S2  RITORNO        massimo >= IB_low  E  chiusura > SMA(InpSmaLen)
#    S3  FALLIMENTO     chiusura < SMA(InpSmaLen)  E  chiusura < IB_low
#                       -> SHORT
#  Stop: massimo di swing CONFERMATO (pivot high, InpPivot barre a
#        destra) + buffer.  Se non c'e' pivot: massimo del ritorno.
#  UNA SOLA OPERAZIONE PER SEDUTA, e blocca ENTRAMBI i lati.
#  Niente ingressi dopo InpCutoff.  Chiusura forzata a InpGoFlat.
#
#  >>> Tutto su BARRA CHIUSA.  Il pivot serve SOLO per lo stop, MAI per
#      il grilletto (nella fonte e' cosi', ed e' il motivo per cui non
#      ridipinge: il ritardo del pivot non tocca la decisione).
#
#  ⏰ ORA SERVER BCM = ORA ITALIANA - 1.  Se si sceglie la finestra USA
#     l'IB va scritto 14:30-15:30 SERVER (non 15:30-16:30).  Se si
#     sceglie la finestra europea, 08:00-09:00 SERVER.
#     Un CSV con InpIbInizio = 15 (o 9) e' da CESTINARE.
#
# ---------------------------------------------------------------------
#  COSA TENGO DELLA FONTE E COSA RIFACCIO -- separati
# ---------------------------------------------------------------------
#  TENGO (il motore, ed e' quasi tutto):
#    - la macchina a tre stati rottura -> ritorno -> fallimento
#    - lo stop STRUTTURALE su pivot confermato + buffer
#    - il vincolo di UNA operazione per seduta su entrambi i lati
#    - il cutoff degli ingressi e il flat serale obbligatorio
#    - la simmetria esatta fra i due lati
#
#  TENGO ANCHE LA GESTIONE, ed e' raro: la fonte ha GIA' il sizing a
#  rischio (riga 692: qty = riskAmount / (tick_di_stop * valore_tick))
#  e la scala di uscite 1R/2R/3R/4R/5R + breakeven.  E' la gestione di
#  casa scritta da un estraneo.
#
#  RIFACCIO:
#    - rischio in PERCENTUALE dell'equity (0,65%) invece di un importo
#      in valuta, cosi' scala a 100k senza toccare niente
#    - la scala si SFRONDA: parziale a 1R + breakeven + runner a 2R
#      (la gestione DAX/Dow di casa), NON cinque scaglioni.  Cinque
#      scaglioni sono cinque manopole in piu' da girare verso il passato
#    - spread come PERCENTUALE dello stop, non in punti (lezione R55)
#    - gli input cosmetici (45 colori e "Show ...") e i ~60 livelli
#      opzionali a default false NON si portano: restano ~10-12 input
