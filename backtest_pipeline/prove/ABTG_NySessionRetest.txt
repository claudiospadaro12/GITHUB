# IPOTESI
#   Nel verso del trend ORARIO (EMA200 su H1), dopo che il prezzo si allontana
#   dalla VWAP di sessione e poi vi RITORNA, si entra sul RETEST -- ma SOLO
#   quando la VWAP ha pendenza e il mercato si espande (non compresso). E' un
#   RETEST-IN-TREND (la geometria che nei referti ha sempre pagato, R42), NON
#   breakout/fade/momentum. Primo motore H1-intraday della flotta + primo
#   motore VWAP (buco reale: tutti i nostri H1/H4 sono SWING, tutto l'intraday
#   nostro e' M5/M15). Il gate slope+espansione E' costitutivo: senza, e' un
#   retest nudo.
#
# CRITERI DI ACCETTAZIONE  (congelati PRIMA dei numeri)
#   - PASSO 0: misurare lo SPREAD reale H1 (logger 74148, mai usato finora) e
#     la FREQUENZA dei retest-VWAP (INFERITA bassa: H1 puro = pochi/settimana).
#     Campione sottile -> valvola R59: il RISCHIO si giudica, il MERITO si
#     sospende finche' n<150.
#   - Verdetto SOLO a tick reali BCM (2024.09.26->2026, un solo regime toro).
#     Screening di REGIME (crollo 2020 / orso 2022) SOLO su NASUSD_EXT OHLC.
#   - VINCOLO DURO: InpCloseAtEnd=1, FLAT a fine seduta USA (ora server), zero
#     overnight. Se un solo trade resta overnight -> il file e' invalido.
#   - Il GATE slope+espansione deve MORDERE: alle 2 tarature (vs OFF) i trade
#     e il PF devono cambiare in modo ordinato. Se OFF == ON -> gate
#     decorativo -> scarto (lezione 0/5 del filtro appiccicato).
#   - Rischio % (MAI il 10% fisso dell'originale). SL strutturale
#     lowest/highest(5) + PAVIMENTO InpMinStopPts (R109).
#   - DUE LATI (long E short), regola di casa 25/08.
#   - Promozione cella: CENTRO dell'altopiano, MAI il picco.
#   - Deve passare i caduti (breakout/fade/momentum): non e' nessuno di questi.
#   - SCORRELAZIONE (da MISURARE): lavora nella finestra apertura USA dove gia'
#     stanno Dow Apertura e PREOPEN_RETEST. Se entra NEGLI STESSI GIORNI ->
#     non diversifica -> penalita'. Da scrivere PRIMA del verdetto.
#
# ==========================================================================
# QUESTO LANCIO E' IL PASSO 0 + MISURA A TICK: NON E' IL VERDETTO.
#   CELLA FISSA con il GATE A SOGLIE NEUTRE (InpVwapSlopeMin=0, InpExpansionMin
#   =0: il gate resta nel codice ma NON morde -- e' l'ablazione "OFF" dichiarata
#   nell'EA). Qui si misurano: FREQUENZA reale dei retest-VWAP su H1, mediana
#   del take in PUNTI INDICE (dal per-trade CSV), costo reale dello spread
#   (implicito nei tick BCM), scala tipica di slope/espansione. SOLO DOPO
#   questa misura si mettono le 2 tarature del gate attorno alla mediana
#   (round successivo, gate ON vs OFF): le soglie NON si inventano prima di
#   aver visto la scala reale delle due grandezze -- regola di casa, dichiarata
#   qui insieme al metodo. Anche lo sweep di InpSlLookback (3/5/8) appartiene
#   al round di taratura, NON a questa misura.
#
# GEOMETRIA DEL LANCIO
#   - UNICO ASSE Y = InpMagic, GEMELLI 769501/769502 (vergini, verificati
#     repo-wide; il 769500 e' il default dell'EA e resta al forward): 2 passate
#     identiche = determinismo + 2 per-trade CSV DISTINTI in Common\Files
#     (abtg_trades_ABTG_NySessionRetest_U30USD_769501/769502.csv). Il per-trade
#     CSV e' il CUORE di questo passo: con una griglia vera sarebbe
#     inutilizzabile (stesso magic -> sopravvive solo l'ultima passata).
#   - MODELLO 4 (tick reali BCM), U30USD NATIVO, H1.
#   - UNA SOLA TRANCHE, FrazioneIS 1.0: la gamba "IS" del generico e' la
#     finestra intera, la gamba "OOS" e' degenere (0 giorni) e si IGNORA.
#     21 mesi = UN SOLO REGIME (toro): merito sospeso se n<150 (R59), rischio
#     SEMPRE (DD e peggior giornata contro il muro).
#
# >>> FUSO DI CASA (NON invertito): U30USD BCM e' a ora SERVER (IT-1).
#     RTH NY 09:30-16:00 ET -> 14:30-21:00 SERVER. Quindi:
#     InpSessionHour=14, InpSessionMin=30 (NON 9:30, che e' l'ora ET);
#     InpCloseHour=20, InpCloseMin=55 (flat poco PRIMA del close 21:00 server;
#     NON 16, che e' l'ora NY dei feed _EXT). La riga di lancio gatta tutti e
#     quattro i valori e RIFIUTA il 9 e il 16.
#
