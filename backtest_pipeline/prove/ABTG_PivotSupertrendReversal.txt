#   stessa gestione: rischio %, 1/3 a mercato + 2/3 pendente, parziale 1R,
#   stop in pari, runner, uscita su flip) con **UNA SOLA DIFFERENZA**:
#
#     la base della banda Supertrend NON e' piu' hl2 dell'ultima candela
#     (ABTG_SupertrendReversal.mq5:361)
#     ma il CENTRO PESATO DEI PIVOT DI SWING CONFERMATI:
#         centro = (2*centro_precedente + pivot_nuovo) / 3
#     bande = centro +/- InpStMult * ATR   (l'ATR RESTA)
#
#   Origine: Pivot SuperTrend, Bhanu Chandra Raju Indukuri, 19/07/2026,
#   https://www.mql5.com/en/code/75110  (idea originale: LonesomeTheBlue,
#   TradingView, open source). L'AUTORE VA CITATO IN TESTA AL .mq5 (§9).
#
#   ✅ Controllo look-ahead gia' fatto sul sorgente: il pivot alla barra
#   `bar` e' quello di `bar - radius` e guarda avanti al massimo fino a
#   `bar`. NON legge barre future. Il costo e' il RITARDO (radius barre),
#   non il repaint.

# ---------------------------------------------------------------------
# IPOTESI (scritta prima di qualunque numero)
#
#   Il nostro Supertrend ricentra la banda a ogni candela sul suo punto
#   medio. Sugli indici, nelle sessioni disordinate, questo fa ballare la
#   banda con il rumore: il flip arriva perche' una candela e' storta, non
#   perche' il trend e' finito — e nel nostro EA il flip e' un'USCITA
#   (InpExitOnFlip, .mq5:177-178), quindi il rumore chiude i runner.
#
#   IPOTESI: ancorando la base alla STRUTTURA (pivot di swing confermati),
#   la banda si muove solo quando si muove la struttura. Attesa:
#     - MENO flip  -> meno uscite per rumore -> trade meno numerosi e piu' lunghi
#     - stop piu' vicino a livelli che il mercato ha davvero girato
#
#   IPOTESI DA SMONTARE (e' questa quella che si testa):
#     "la geometria della base NON conta: cambiarla non sposta l'OOS".
#   Se i numeri OOS sono indistinguibili da quelli della cella STREV di
#   riferimento, l'ipotesi resta in piedi e il candidato si chiude. E'
#   un esito valido e va scritto.
#
