#
#   BASE       ADR = ATR(PERIOD_D1, InpADRPeriod) letto sulla BARRA D1
#              CHIUSA di ieri -> indice [1] della serie. In punti.
#              🔴 Mai l'indice [0]: sarebbe la barra D1 in corso.

#   LIVELLI    trigger = ADR * InpTriggerPct / 100
#              resto   = ADR - trigger
#
#   INGRESSO   (specchio esatto, nessuna asimmetria)
#     LONG  se (Bid - minimo di OGGI)   > trigger   e InpAllowLong
#     SHORT se (massimo di OGGI - Ask)  > trigger   e InpAllowShort
#     dove "minimo/massimo di OGGI" = iLow/iHigh(PERIOD_D1, 0), cioe'
#     l'escursione corrente della seduta: informazione legittima, non
#     look-ahead (verificato nell'originale).
#
#   USCITA     TP = resto punti     SL = trigger punti
#              + chiusura forzata a fine giornata di trading
#
#   ⭐ IL PUNTO CHE RENDE LA GRIGLIA HONESTA:
#      SL e TP sono I DUE PEZZI DELLO STESSO BUDGET.
#        InpTriggerPct=30 -> SL 30 %, TP 70 %, payoff 2,33 (win-rate basso)
#        InpTriggerPct=60 -> SL 60 %, TP 40 %, payoff 0,67 (win-rate alto)

#      esiste un altopiano, e' un altopiano vero e non un artefatto.
