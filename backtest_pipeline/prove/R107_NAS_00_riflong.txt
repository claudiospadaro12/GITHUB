#  >>> I CRITERI DI DETTAGLIO SONO [DA FIRMARE].
#
#  PERCHE' NON E' UN METRO:
#    un METRO e' una cella che RIPRODUCE un numero AGLI ATTI. Sul Nasdaq
#    non esiste nessuna sedia viva con questa geometria (il magic 770201
#    e' SPENTO e resta spento) e non esiste nessun numero agli atti da
#    riprodurre. Quindi qui NON c'e' nessun gate G0 e NON si puo' dire
#    "il banco e' sano" sulla base di questa cella.
#    Serve a UNA cosa sola: dare un DENOMINATORE alla cella short. Senza,
#    "PF short 0,9" non si saprebbe se e' un giudizio sul lato o sulla
#    geometria trasposta.
#
#  CHE GEOMETRIA E' QUESTA:
#    E' LA GEOMETRIA VIVA DEL DOW, TRASPOSTA DI PESO su NASUSD.
#    Copia carattere per carattere del blocco input di
#    prove\R101_DOW_00_viva.txt, con @SIMBOLO cambiato e il blocco R30
#    aggiunto (vedi sotto). Stessa ora 14:30 SERVER (apertura USA),
#    stesso range 35', stesso EntryMode=2 (RETEST), stesso buffer 1000
#    punti, stesso offset 400, stesso EMA H4, stesso floor stop 500,
#    stessa chiusura 17:30 server, stesso rischio 1%.
#
#  >>> IL LIMITE DI QUESTA SCELTA, DETTO PRIMA DEI NUMERI:
#      buffer e offset sono in PUNTI ASSOLUTI, e i due indici non hanno
#      la stessa scala. 1000 punti = 10 punti indice: su un Dow a ~44.000
#      sono lo 0,023%, su un Nasdaq a ~20.000 sono lo 0,05% -- il DOPPIO
#      in termini relativi. Trasporre e' quindi una SCELTA, non una
#      neutralita'. E' stata presa cosi' apposta: qualunque riscalatura
#      (per ATR, per prezzo, per volatilita') sarebbe un PARAMETRO NUOVO
#      deciso a tavolino senza misura, cioe' l'inizio della pesca.
#      CONSEGUENZA, che il referto DEVE scrivere: se le celle NASUSD
#      escono rosse, il risultato e' "LA GEOMETRIA DEL DOW NON SI
#      TRASPORTA SUL NASDAQ", NON "il Nasdaq non ha edge in apertura".
#      Sono due frasi diverse e solo la prima e' misurata qui.
#
#  IL BLOCCO R30 (15 input in fondo, prima di InpMagic): esiste SOLO in
#  ABTG_Nasdaq_Apertura_US.mq5 -- regime di volatilita' adattivo e filtro
#  S/R, aggiunti nel round 30 e MAI validati. Sono pinnati SPENTI
#  (InpUseVolRegime=0, InpUseSRFilter=0). MISURATO nel sorgente il 25/08:
#  UpdateVolRegime() ritorna alla prima riga se l'interruttore e' falso,
#  VolRegimeSL() ritorna lo stop invariato, SRBlocked() ritorna false
#  subito. Con i due interruttori a 0 il motore Nasdaq E' il motore Dow.
#
#  ALTRE DUE DIFFERENZE DI FAMIGLIA, dichiarate:
#    - il .mq5 del Nasdaq e' version 1.02, quello del Dow 1.01: la
#      differenza E' il blocco R30 (diff del core fatto il 25/08).
#    - il Nasdaq NON ha InpAllowReverse (ce l'ha solo il DAX): infatti
#      qui non compare, ed e' giusto cosi'.
#
