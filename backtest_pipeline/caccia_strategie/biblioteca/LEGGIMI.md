# 📚 BIBLIOTECA — l'archivio permanente del materiale raccolto fuori

_Creata il 18/08/2026 su richiesta di Claudio: "facciamo la copia totale di
tutto quello che si trova sul web". Tradotto nel metodo di casa: **tutto cio'
che e' GRATUITO, PUBBLICO e LEGITTIMO si scarica e si archivia QUI**, cosi'
nessuna caccia butta via il bottino e ogni analisi futura parte dal file
vero, non dal ricordo di una chat._

## Le stanze

| cartella | cosa ci va | regola |
|---|---|---|
| `set/` | file `.set`/`.ini` di preset scaricati (prop e non) | nome: `<EA>_<preset>_<fonte>_<AAAA-MM-GG>.set` |
| `sorgenti/` | sorgenti `.mq5`/`.mqh` GRATUITI col loro sorgente pubblico | SEMPRE con licenza e autore in testa al file o in una riga del catalogo |
| `schede/` | estratti testuali: pannelli input trascritti, manuali pubblici, regole | una scheda = un file `.md` con URL e data |
| `dati/` | dataset scaricati (calendari news CSV, storici, liste eventi) | nome: `<COSA>_<periodo>_<fuso se noto>_<fonte>_<AAAA-MM-GG>.<ext>` — il FUSO si dichiara SEMPRE |

## Le regole della biblioteca

1. **CATALOGO.md e' l'indice**: ogni file archiviato ha UNA riga li' dentro
   (data, fonte/URL, cosa e', perche' e' stato preso, chi l'ha preso).
   Un file senza riga di catalogo non esiste.
2. **Solo materiale legittimo**: gratuito e pubblico. I prodotti a pagamento
   entrano SOLO come scheda (parametri dichiarati, screenshot descritti) —
   mai il file di un prodotto venduto.
3. **La biblioteca conserva, non giudica**: il giudizio sta nei dossier e nei
   referti che la citano. Ma la provenienza sta qui, per sempre.
4. **Commit e push a ogni deposito.** Non pushato = perso.
