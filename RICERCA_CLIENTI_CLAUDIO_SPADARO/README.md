# RICERCA CLIENTI CLAUDIO SPADARO

Ricerca web di aziende dei settori: tinteggiature, imbiancature, ripristino facciate,
cappotti termici, resine civili e industriali, stucchi e opere murarie.

Zone: Emilia-Romagna (tutte le province) + Varese, Como, Lecco, Pavia, Pesaro e Urbino.
Totale: 247 aziende. Dati raccolti il 18/08/2026 da siti aziendali, directory di settore
e schede camerali pubbliche. I campi vuoti indicano dato non trovato (nessun dato inventato).

In ogni CSV le aziende sono ordinate per vicinanza chilometrica: si parte dal capoluogo
e ogni riga e' l'azienda piu' vicina alla precedente (colonna "Distanza dal precedente (km)",
in linea d'aria tra i comuni).

- `csv/` — un file per provincia con le colonne: Denominazione, Indirizzo, Città o Paese, Provincia, Telefono, Email, Numero Addetti, Anno di Fondazione, Di cosa si occupano, Distanza dal precedente (km), Sito Web, Fonte dati
- Il file Excel completo (un foglio per provincia) è stato consegnato in chat; qui i dati sono in formato CSV.
