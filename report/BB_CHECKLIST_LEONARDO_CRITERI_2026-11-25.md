## Operazionalizzazione (b = barra del bulge; i0 = barra del minimo di ampiezza delle bande nelle 20 barre fino a b; s = barra del segnale; W = 15 barre che finiscono in i0; width = ampiezza Bollinger 20/2; sd = dev. standard 20; SMA50(sd); ATR(14) a media semplice)
- **Congestione 25%.** CS valida se >= 4 su 5: (1) width[i0] <= 0,9 x width[i0-15]; (2) range medio in W <= 0,8 x range medio delle 50 barre prima, e max range <= 2 x medio; (3) |close[i0]-close[i0-15]| <= 1 ATR; (4) nessuna barra in W con range > 1,5 ATR; (5) sd[i0] < SMA50(sd) e |sd[i0]-sd[i0-5]| <= 15%. Altrimenti CDA valida solo se TUTTI: sd[i0] < sd[i0-10]; sd < SMA50; width[i0]/width[i0-15] fra 0,70 e 0,85; nessuna barra > 1,5 ATR; R2 della regressione lineare delle chiusure in W >= 0,5. Congestione valida = 25 punti, altrimenti 0.
- **Bulge 25% (TUTTI i 6 devono essere SI, altrimenti pattern INVALIDO):** (1) width[b] >= 1,5 x width[i0]; (2) sd[b] > SMA50(sd); (3) almeno 2 barre fra i0 e b con range fra 1,5 e 3 ATR (ATR a i0); (4) (close[b]-close[i0]) x dir >= 2,5 ATR e almeno 60% delle barre nel verso; (5) |close[b]-SMA20[b]| >= 1,5 ATR; (6) b - i0 <= 20.
- **Ritracciamento/rientro 20%** (richiesto >= 80% dei criteri, altrimenti INVALIDO; punti = 20 x frazione): range medio delle barre fra b e s <= 0,7 x range medio dell'impulso; nessuna barra > 1,5 ATR; ombre <= 1,5 x corpo in >= 80% delle barre; nessun engulfing impulsivo (barra > 1,0 ATR con corpo >= 70% del range contro il trade); CONT: movimento netto verso la banda opposta; INV: rientro verso la mediana senza toccare la banda opposta; bande in restringimento (width[s] < width[b]).
- **Comportamento delle bande 15%** (frazione di 3 x 15): restringimento dopo il bulge; INV: banda dell'impulso piatta o a favore (pendenza su 3 barre <= 0 verso l'esterno; CONT: nessuna espansione contraria; width[s] <= 1,05 x width[s-3]).
- **Test 10%** (frazione di 2-3 x 10): CONT: test della banda opposta (per definizione) e barra del test <= 1,5 ATR; INV: test della banda dell'impulso (per definizione), nessun contatto precedente con la opposta, banda dell'impulso piatta o in compressione.
- **Conferme 5%** (frazione di 4 x 5): sd in calo (sd[s] < sd[s-3]); sd < SMA50; SMA50 dei prezzi inclinata a favore (5 barre); assenza di notizie imminenti: **non misurabile qui, contata SI (neutra)**.
- **Invalidazioni assolute (un solo SI = INVALIDO):** CONT: barra > 1,5 ATR nel ritracciamento o nel test; ritracciamento disordinato (spike: ombra > 2 x corpo con range > 1 ATR); sd >= SMA50 al segnale. INV: barra > 1,0 ATR nel rientro; banda dell'impulso inclinata contro (3 barre); width[s] > 1,05 x width[s-3] (si gonfia); tocco della banda opposta; sd >= SMA50.
- **Bonus** (non pesati): rigetto non impulsivo sulla barra del test (pin bar: ombra >= 2 x corpo, doji: corpo <= 30% del range); rientro graduale (>= 5 barre fra b e s); chiusura della barra del segnale dentro la banda testata.
- **Qualita:** solidita >= 85 Ottimo, 70-84 Buono, 55-69 Medio, < 55 Debole (soglie di Leonardo); INVALIDO = fuori dai gradi.
