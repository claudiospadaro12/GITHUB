How these were tested

Each strategy was tuned on 2021.01.01 – 2024.03.01, then both versions — original and Zairex — were backtested on 2024.03.08 – 2026.08.22, a period the tuning never touched, with every tick based on real ticks. A set only made this pack if it came out ahead there.

Only the ten exit settings were changed. Entries, filters and sizing are exactly the original author’s.

Every backtest on this page was run on Vantage Markets (Build 6182) at 100% real ticks history quality, with overrideAutoLoadLotsSettings set to false so each set used its own lot settings.

The two account tests above ran the whole pack together to 2026.09.14. Read the unseen one first: the full-history test starts inside the tuning period, so it flatters these sets by design. Both hit the same worst drawdown of 4,871 — it happened after 2024.03.08, inside the unseen stretch.

Reading the numbers

  • Compare a set with its own original, row by row. Account settings differed between test batches, so raw profit is not comparable between rows — that is why this page shows ratios and changes.
  • Profit ÷ drawdown does not depend on lot size, so those dots share one scale.
  • Every set shown traded at least 50 times in the test period.

Before you load them

  • Set overrideAutoLoadLotsSettings to false in the AutoLoader, so every set uses its own lot settings. Leave it on and the AutoLoader overrides them, and you are no longer trading what was tested.
  • Check the symbol names. These use XAUUSD+, GBPUSD+ and BTCUSD. If your broker names them differently, change ForceSymbol first or the AutoLoader will not trade them.
  • Magic numbers 9639001–9639015 are reserved for this pack, so they will not clash with each other.
  • Trade comments start with Zairex, so you can spot these trades in the terminal.
  • Past results do not guarantee future ones. Test on demo before running real money.
