# Perturbazione dei parametri dei set US30 volatility M15 (22/11/2026, scritta PRIMA dei numeri)
Passo 4 della guida di Wim ("variare i parametri: almeno il 70% delle varianti in profitto"; `UBS_MANUALE_PROCEDURA_2026-11-21.md`). Solo tester/demo; nessun consiglio su lotti o taglie.
- **Set:** `US30_VOL_M15_g` (**vincolante**: unico a superare V3 a tick), `US30_VOL_M15_c` e `US30_VOL_M15_a` (**informativi**: il verdetto di c e a, "non passa", **non cambia** qualunque cosa esca; la soglia DD 1,5 di V3 resta 1,5).
- **Varianti:** per ognuno dei 9 parametri liberi del set (`minSize`, `AtrPeriod`, `DevFactor`, `Exit_stop`, `Exit_limit`, `Exit_TrailSL_size`, `Exit_TrailSL_Start`, `Exit_TrailTP_size`, `Exit_TrailTP_Start`) il valore centrale piu e meno **un passo** (il passo scritto nel set stesso), una variante alla volta; fuori dalla gamma del set = non eseguita (3 casi). **51 passate.**
- **Esecuzione:** clone `U30USD_T` con tick reali (Modello 4), M15, 01/01/2025 - 13/11/2026, lotto fisso 0,1, deposito 100000 EUR, stessi input del centro (a parte il parametro variato). Contatore di campagna +51.
- **Misura:** quota di varianti con PF > 1,0 sull'intera finestra. **Soglia di Wim: >= 70%.** Riportati in piu (informativi): PF minimo, PF mediano, quota con PF >= 0,8 volte il PF del centro (g 1,88; c 1,18; a 1,60), differenza di operazioni rispetto al centro.
- **Previsioni (scritte ora):** P-1 `g` passa (>= 70% con PF > 1): 65%. P-2 `c` passa: 55%. P-3 `a` passa: 50%. P-4 PF mediano delle varianti di `g` >= 1,5: 55%. P-5 almeno un parametro con PF < 1 in entrambe le direzioni per `g`: 35%.
- **Limiti:** un passo solo (non una griglia), una finestra di 22 mesi in un solo regime (Dow in rialzo), nessun fuori campione lungo; la perturbazione non sostituisce l'hold-out.
